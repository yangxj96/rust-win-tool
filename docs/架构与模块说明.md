# 架构与模块说明

## 总体结构

应用是单一 Rust 二进制 crate。当前按功能域组织代码：UI 页面调用对应功能模块，应用状态保存交互和持久化状态；Windows API、文件对话框和日志等横向能力分别放在平台与支撑模块中。现阶段不额外引入严格的分层架构。

```text
src/main.rs
  └── app::run()
      └── app/bootstrap.rs：提权、单实例、日志和 GPUI 窗口装配
          ├── app/state.rs：AppState 和共享状态类型
          │   ├── app/state/services.rs
          │   ├── app/state/cleanup.rs
          │   ├── app/state/scripts.rs
          │   ├── app/state/tools.rs
          │   └── app/state/settings.rs
          ├── features/：服务、清理、脚本和工具业务实现
          ├── platform/：Windows 生命周期集成和原生文件对话框
          ├── shared/、support/：共享错误和日志
          └── ui/：GPUI 主窗口、页面、组件、文案和主题
```

## 启动和生命周期

1. `src/main.rs` 仅声明顶层模块并调用 `app::run()`。
2. `src/app/bootstrap.rs` 在 Windows 上检查提权状态和单实例；初始化日志后创建 GPUI 应用、窗口及 `AppState`。
3. 主窗口打开后异步刷新服务状态，并安装 Windows 通知区域图标。
4. `src/platform/windows/` 封装提权、单实例和托盘等 Windows 生命周期功能。

提权取消时不继续以普通权限运行。UAC、单实例和托盘属于 Windows 特定行为。

## 状态、界面与功能域

- `src/app.rs` 是应用门面，导出 `AppState` 等状态类型，并把启动交给 `bootstrap`。
- `src/app/state.rs` 保存 `AppState` 字段、状态模型、通用状态逻辑和错误映射；各子模块按页面域实现状态操作。
- `src/ui/main_window/` 包含主窗口和各页面的渲染、交互处理；`src/ui/components.rs` 提供共享视觉组件，`src/ui/input.rs` 管理局部文本输入。
- `src/features/services/` 封装 Windows 服务管理、数据持久化及服务操作。
- `src/features/cleanup/` 封装垃圾文件扫描、清理和 Navicat 规则。
- `src/features/scripts/` 保存自定义脚本数据并执行脚本命令。
- `src/features/tools/` 按进程、端口、监控、网络、启动项和系统信息组织工具实现。
- `src/ui/i18n.rs` 定义中英文文案；界面通过 `AppState::t()` 读取翻译。
- `src/ui/theme.rs` 保存主题颜色，再由 GPUI 组件转换为 `Rgba`。

## 后台任务与错误

系统查询、服务控制、文件操作和注册表操作可能阻塞。UI 事件将这些工作提交给 GPUI `background_spawn`，调用对应的 `features` 或 `platform` 功能模块；任务结束后回到主线程更新 `AppState` 并通知界面刷新。

跨功能域的 `BackendError` 位于 `src/shared/error.rs`。服务错误的显示文本保留用于 UI 错误映射的关键词。操作仍受 Windows 权限、目标程序状态和系统 API 结果影响。

## 数据流示例：服务刷新

```text
用户点击刷新
    ↓
MainWindow 在 GPUI 后台任务中调用 features::services::operations
    ↓
Windows 服务控制管理器 API 返回服务信息
    ↓
后台任务回到 GPUI 主线程
    ↓
AppState 更新服务状态和提示
    ↓
GPUI 通知并重绘服务页面
```

其他慢操作采用相同模式。不要在 GPUI 事件处理器内直接运行耗时的系统 API、PowerShell 子进程或大量文件遍历。

## Windows API 与依赖

- `gpui`：桌面窗口与渲染。
- `serde`、`serde_json`：设置、服务列表和自定义脚本数据。
- `thiserror`：共享错误类型。
- `winreg`：Windows 注册表。
- `windows-sys`：Service Control Manager、进程、网络、文件系统、Shell、窗口和系统信息 API。
- `raw-window-handle`：取得原生窗口句柄以安装托盘图标。
- `winresource`：Windows 图标及版本资源构建。
