# 功能使用手册

## 界面和导航

主窗口左侧是页面导航，右侧显示当前页面。页面包括服务管理、系统工具、垃圾文件清理、脚本和设置。标题栏提供窗口拖动、最小化、最大化和关闭操作；窗口也支持调整大小。

应用不注册全局键盘快捷键。键盘输入用于可编辑的搜索框、脚本名称和脚本内容等字段。

## 服务管理

### 管理服务列表

服务列表只保存用户选择关注的服务，不会默认把所有系统服务加入列表。

1. 点击“添加”，打开服务选择窗口。
2. 输入服务名或显示名称筛选系统服务，并选择目标项。
3. 确认添加后，该服务会出现在管理列表中。
4. 在列表中可以查看状态、刷新状态、启动或停止服务，也可以移除关注项。

移除服务只会从应用的管理列表移除，不会卸载 Windows 服务。

### 筛选、详情和启动类型

服务页支持搜索、按状态筛选和排序。详情窗口显示服务状态、启动类型、程序路径、运行账户、进程 ID、描述、依赖项和依赖该服务的其他服务。启动类型可设为自动、手动或禁用；这会更改 Windows 服务配置。

服务的启动、停止、查询和配置变更可能因系统策略或服务依赖而失败。错误信息会在界面中显示。停止系统关键服务可能影响 Windows 或其他应用，请先确认服务用途。

### 导入、导出和历史

- 导出会把当前关注列表保存为 JSON 文件。
- 导入会**替换**当前关注列表，然后刷新导入服务的状态；不会与旧列表合并。导入前建议先导出现有列表备份。
- 页面历史记录用于查看本次运行期间的服务操作；它不是长期审计日志。

数据结构示例见[配置与数据格式](配置与数据格式.md)。

## 系统工具

工具页包含系统信息、进程、实时监控、网络诊断和启动项。

### 系统信息

查看 Windows 版本和版本号、计算机名、当前用户、处理器、核心数和内存等信息。信息由后台任务读取，可通过页面操作重新刷新。

### 进程

进程列表显示进程名称、PID、CPU 和内存信息，并支持按内存、名称或 PID 排序。结束进程前会显示确认操作。PID 0 和 PID 4 被保护，应用拒绝直接终止这两个进程。结束其他进程仍可能造成未保存数据丢失或影响正在运行的程序。

### 实时监控

监控视图采集 CPU、内存、磁盘空间及网络收发速率。CPU 和网络速率由相邻采样值计算；首次采样可能显示为零或尚无变化。

### 网络诊断

- **DNS 查询**：通过 Windows/系统解析器解析输入主机名，并列出解析地址。
- **Ping**：通过 Windows ICMP API 发送 IPv4 请求；当前实现不支持 IPv6 ping。
- **TCP 端口连通性**：连接指定主机和 TCP 端口，判断在超时范围内是否能够建立连接。
- **本机端口查询**：列出本机 TCP/UDP 端口占用信息，并尝试显示对应进程名称。受权限限制的进程可能没有名称。

网络结果受 DNS、路由、防火墙、目标主机状态和权限影响；端口连通不代表目标服务可正常完成业务请求。

### 启动项

启动项来自当前用户和本机的 Run 注册表项，以及当前用户和公共启动文件夹。禁用操作会把 Run 项移至配套的 `RunDisabled` 注册表位置，或把启动文件移入 `disabled` 子目录；重新启用时会移回原位置。应用不删除启动项内容，但其他程序仍可能修改这些位置。

修改本机级注册表项或公共启动目录时可能需要管理员权限。禁用未知项目可能阻止合法软件启动，建议先核对名称和命令。

## 垃圾文件清理

扫描范围由固定类别白名单决定：

| 类别 | 大致位置 | 备注 |
|---|---|---|
| 用户临时文件 | 当前用户临时目录 | 可能包含正在使用的临时文件 |
| Windows 临时文件 | Windows 目录下的 `Temp` | 通常需要管理员权限 |
| 缩略图缓存 | 当前用户 Explorer 缓存目录中的缩略图文件 | Windows 可能随后重新生成 |
| Windows 更新缓存 | `SoftwareDistribution\Download` | 通常需要管理员权限，系统可能重新下载更新内容 |

使用流程：

1. 点击扫描，查看各类别估算的文件数和大小。
2. 选择要清理的类别。
3. 选择移入回收站或永久删除。
4. 检查确认对话框中的类别和估算量，再执行清理。

扫描值是执行前的估算；文件可能在扫描和清理之间变化。被占用、无法访问或需要额外权限的文件可能被跳过。遍历不会跟随重解析点。永久删除不可撤销；回收站内的文件可恢复，直到回收站被清空。

“清空回收站”会永久删除其中所有项目，不限于本应用清理的文件，并且不可恢复。执行前请确认回收站中没有需要保留的内容。

## 脚本

脚本页包含内置操作和用户自定义脚本：

- **重置 Navicat**：删除当前用户下指定 Navicat 注册子项，并清理符合条件的 CLSID 残留。符合条件的 CLSID 项会尝试先备份到 `HKCU\Software\RustWinTool\Backup\<时间戳>\CLSID`；备份失败不一定会阻止后续删除。`Registration17XCS` 和 `Update` 两个指定子项在当前实现中直接删除，不纳入上述 CLSID 备份。该操作可能无法完整回滚，执行前请自行导出相关注册表分支。
- **刷新 DNS 缓存**：执行 `ipconfig /flushdns`。
- **自定义脚本**：可保存 CMD 或 PowerShell 脚本，查看、运行和删除自定义条目。

自定义脚本保存在 `config/scripts.json`。执行时应用会把脚本内容写入临时文件，调用对应解释器，并在执行后尝试删除临时文件。脚本以应用当前权限运行；由于应用启动时会请求管理员权限，自定义脚本通常也拥有提升后的权限。脚本没有沙箱隔离。只运行自己编写或完全审查过的脚本。

脚本输出显示在应用内。命令失败时会返回错误输出；PowerShell 子进程在 Windows 上以隐藏窗口方式执行。

## 设置、日志和托盘

- **语言**：中文或英文。默认中文。
- **主题**：深色或浅色。默认深色。
- **日志目录**：设置页中的“打开日志目录”按钮会打开 `config/logs`。
- **系统托盘**：双击托盘图标显示窗口；右键菜单提供显示、隐藏和退出。关闭窗口的行为由 GPUI 窗口逻辑处理；需要退出时可从托盘菜单选择退出。

日志是追加写入的文本文件；日志写入失败不会中断主界面。日志内容可能包含操作结果和系统路径，分享日志前请检查隐私信息。
