# 快速开始

## 1. 环境要求

- Windows 10 或 Windows 11；服务管理、启动项、进程、回收站和注册表功能使用 Windows API。
- 已安装 Rust 稳定版工具链和 Cargo。
- 可访问 Cargo 配置的依赖源，以便首次构建下载依赖。

可在 PowerShell 中检查工具链：

```powershell
rustc --version
cargo --version
```

## 2. 获取源码

```powershell
git clone <仓库地址>
Set-Location rust-win-tool
```

如果已经有仓库副本，进入包含根目录 `Cargo.toml` 的项目目录即可。

## 3. 构建和运行

开发构建并启动：

```powershell
cargo run
```

只构建、不启动窗口：

```powershell
cargo build
```

构建优化后的发布二进制：

```powershell
cargo build --release
```

生成的可执行文件位于 `target\debug\rust-win-tool.exe` 或 `target\release\rust-win-tool.exe`。项目当前没有单独的安装器或自动更新程序；分发时需要同时考虑可执行文件旁的 `config` 数据目录。

## 4. 首次启动

1. Windows 会显示用户账户控制（UAC）提示。程序在 Windows 上会请求管理员权限，以便管理系统服务及访问部分系统目录。
2. 接受 UAC 后应用启动；取消提权时程序不会继续以普通权限运行。
3. 首次运行会在可执行文件旁创建 `config` 目录，并按需读写设置、服务列表和脚本数据。
4. 默认界面语言为简体中文，默认主题为深色。
5. 主窗口显示服务管理页。应用同时初始化系统托盘图标。

如果把程序放在没有写权限的目录，应用可能无法保存 `config` 内容或日志。开发时建议在自己有写权限的工作目录中运行。

## 5. 常用开发命令

```powershell
cargo fmt --check
cargo clippy -- -D warnings
cargo test
cargo build
```

这些命令分别用于检查格式、运行 Clippy 严格检查、运行 Rust 测试和构建应用。GUI 的交互效果、UAC、托盘和实际系统操作仍需在 Windows 桌面环境中单独检查。

## 6. 配置和日志位置

```text
<可执行文件所在目录>/config/
├── managed_services.json
├── settings.json
├── scripts.json
└── logs/
    └── rust-win-tool.log
```

详细字段和示例见[配置与数据格式](配置与数据格式.md)。卸载或移动程序前，如需保留偏好设置、服务列表和自定义脚本，请先备份 `config` 目录。
